authN

A centralized authentication service built on hexagonal architecture. The core domain has no framework dependencies; HTTP, PostgreSQL and Redis sit behind ports and adapters.

  • Email/password with Argon2id hashing
  • OAuth 2.0 for Google, GitHub and Apple, with state-token CSRF protection
  • JWT access and refresh tokens with configurable TTLs
  • Redis sessions with automatic expiry
